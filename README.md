# Последние 5 дней: Неизвестный вирус

Небольшой прототип сюжетного мода для **Minecraft Java Edition 1.21.1 + Fabric**.

## Игровая цель
У тебя есть пять игровых дней (120 000 игровых тиков), чтобы собрать компоненты экспериментального лекарства:
- 1 паучий глаз (`Spider Eye`)
- 1 бутылка мёда (`Honey Bottle`)
- 1 слеза гаста (`Ghast Tear`)

## Команды
- `/virus start` — начать или перезапустить сценарий.
- `/virus status` — проверить оставшееся время.
- `/virus cure` — проверить компоненты и завершить сценарий победой.

Команды доступны игрокам с правами на команды (обычно оператор в одиночном мире с включёнными читами).

## Сборка
1. Установи JDK 21 и Gradle.
2. Открой папку проекта в IntelliJ IDEA или другом IDE с поддержкой Gradle.
3. Выполни `gradle build`.
4. Готовый JAR будет в `build/libs/`.
5. Помести JAR в папку `mods` Minecraft с Fabric Loader и Fabric API для 1.21.1.

Официальная документация Fabric: https://docs.fabricmc.net/develop/getting-started/creating-a-project

## Важно
Это стартовый прототип игровой механики: компоненты используют предметы ванильного Minecraft; отдельные модели, заражённые мобы, лаборатории и сюжетные задания пока не добавлены.
